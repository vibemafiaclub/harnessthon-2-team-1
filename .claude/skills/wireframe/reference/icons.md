# 아이콘 참조

와이어프레임에서 쓰는 아이콘은 Google **Material Symbols (Outlined)** 로 고정한다. 이 문서에 있는 아이콘만 쓴다. 여기 없는 아이콘이 필요하면 [fonts.google.com/icons](https://fonts.google.com/icons)에서 Outlined 스타일로 고른 뒤, 이 표에 이름·의미·path를 추가하고 나서 쓴다.

## 왜 Material로 고정하는가

- 아이콘 하나에 의미 하나가 이미 널리 합의돼 있다. 보는 사람이 "이게 무슨 뜻이지"를 묻지 않게 하는 것이 목적이다.
- 이름이 곧 의미다. `more_vert`, `chevron_right`처럼 이름을 Annotation과 Inventory에 그대로 적으면 디자이너·개발자가 같은 것을 가리킨다.
- Apache 2.0 라이선스라 path를 그대로 써도 된다. Figma 라이브러리에 아이콘이 없을 때 벡터로 만들 수 있다.

## 사용 규칙

1. **유니코드 글리프와 이모지를 쓰지 않는다.** `‹`, `›`, `×`, `☰`, `→`, `✓` 같은 문자를 아이콘 대신 쓰지 않는다. 폰트마다 다르게 보이고 의미가 흐리다.
2. **아이콘 하나에 의미 하나.** 같은 의미에는 항상 같은 아이콘, 같은 아이콘은 항상 같은 의미. 예: `chevron_right`는 "다른 화면으로 이동"에만 쓰고 "펼치기"에는 `expand_more`를 쓴다.
3. **라벨 없이 쓸 수 있는 아이콘은 정해져 있다.** 표의 "단독 사용" 열이 "가능"인 것만 텍스트 없이 둔다. 그 외는 텍스트 라벨과 나란히 둔다. 확신이 없으면 라벨을 붙인다.
4. **크기는 24px 하나.** 텍스트 앞에 붙는 인라인 아이콘만 20px을 허용한다. 색은 본문 `#1A1A1A` 또는 보조 `#767676`만 쓴다. Primary CTA 안에서는 흰색.
5. **Component Inventory와 wireframe.md 핸드오프 절에 아이콘 표를 둔다.** 쓴 아이콘마다 Material 이름, 의미, 쓰인 화면을 적는다. Annotation에서 아이콘을 언급할 때도 Material 이름을 괄호로 적는다. 예: "더보기 메뉴(more_vert)".
6. **의미가 겹치는 짝은 한 프로젝트에서 하나만 고른다.** `more_vert`/`more_horiz`, `favorite`/`star`는 각각 하나로 통일한다.

## wireframe.md에 적는 방법

트리에서 `icon` 노드 한 줄이다. 따옴표 안이 Material 이름이고, 단독 아이콘은 `label=`로 의미를 적는다. 라벨과 함께 쓰는 아이콘은 옆에 `text` 노드를 둔다.

```
icon "arrow_back" size=24 label="뒤로 가기"
row "ShareButton" w=hug h=44 gap=4 align=center
  icon "share" size=20
  text "공유" style=body
```

Figma 변환 에이전트는 Material Symbols 라이브러리(예: "Material Design Icons")에서 같은 이름을 찾아 인스턴스로 놓는다. 라이브러리에 없으면 아래 "Path 데이터"로 24×24 벡터를 만든다.
