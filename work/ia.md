> 01-planner 산출물. 소비자: 02-wireframer. 게이트 1 결과(축 1-**B 일정 중심** 사람 선택 / 축 2-A 합쳐 보고 필터 / 축 3-A 링크 응답) 기준으로 작성. 축 선택 근거는 `work/decisions.md`.

## 3. 핵심 흐름 3개

**F1. 편성 → 확정 (주 흐름)**
`calendar-overview(홈) → home-meetings → meeting-create → meeting-dates → [OS 공유 시트] → guest-response → meeting-detail → meeting-confirm → calendar-overview(확정 모임이 셀에 찍힘)`

**F2. 지인 풀 만들기 (초기 세팅)**
`contacts-list(빈 상태) → contact-edit → contacts-list → contact-edit(그룹 추가) → contacts-list(그룹 칩 필터)`

**F3. 조망 → 처리 (매주 반복)**
`calendar-overview(홈 · 요약 행 "날짜 미정 3건 · 마감 임박 D-1") → home-meetings(확정 대기 섹션 상단) → meeting-detail(마감 지남 · 미회신 1명) → [리마인드 + 마감 연장] 또는 → meeting-confirm(미회신 제외 확정) → calendar-overview(셀 "2건 · 겹침" 확인) → meeting-detail(겹친 모임 "날짜 다시 잡기") → meeting-dates`

## 5. 화면별 상태 메모 (02가 목데이터·와이어에 반영)

- `calendar-overview` (홈): 위에서부터 mobile-header(제목 "우리 일정", 우측 "새 모임" compact 버튼) → 소유자 필터 칩 행 → **요약 행**(list-row 1개: "날짜 미정 모임 N건 · 마감 임박 {모임} D-n", chevron → `home-meetings`; 미정 모임 0건이면 숨김) → 월 달력 → 선택한 날짜의 모임 목록. 확정 모임만 달력에 표시, 후보는 표시하지 않는다(가정 14). 빈 상태(모임 0개)는 `empty-state` "첫 모임을 만들어 보세요" → `meeting-create`.
- `home-meetings`: 섹션 순서 = 확정 대기 → 회신 대기 → 준비 중 → 확정 → 완료. 홈 요약 행에서 진입 시 `확정 대기` 섹션이 첫 스크롤. 빈 상태는 `empty-state`.
- `meeting-detail`: 상태 5개 중 `준비 중`(CTA "후보 보내기") / `회신 대기`(CTA "리마인드", 보조 "마감 연장") / `확정 대기`(CTA "확정하기", 보조 "마감 연장") / `확정`(CTA "링크 다시 공유", 보조 "날짜 다시 잡기") / `완료`(CTA 없음). 02는 대표 상태 1개(`확정 대기`)를 와이어로 그리고 나머지는 CTA 문구 변형만 기록.
- `guest-response`: 상태 2개 — 응답 전(이름 선택 + 후보 목록 + 제출) / 확정 후(시간·장소·구성원). 02는 응답 전 상태를 기본으로.
