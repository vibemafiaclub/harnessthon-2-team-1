# contacts-list — 지인 목록

## 목적

청첩장을 줄 40~100명을 소유자·그룹 칩·검색으로 걸러 본다. 한 사람에 그룹 칩이 여러 개 붙어 "사람이 단위, 그룹은 태그"(brief C2)를 드러낸다. PRD §4-1.

## 진입 / 이탈

- 진입: `{component.mobile-tab-bar}` 탭 3 "지인" / `contact-edit` 저장·뒤로가기
- 이탈:
  - 헤더 우측 "추가" → `contact-edit` (신규 모드)
  - 블록 6 지인 행 → `contact-edit` (해당 personId, 수정 모드)
  - 빈 상태 버튼 → `contact-edit` (신규 모드)
  - 탭바 "달력" → `calendar-overview`, "모임" → `home-meetings`

## 프레임

- 390 × 콘텐츠 높이 (약 1,000, 필터 상태 기준). 세로 스크롤. 블록 1~4는 상단 고정하지 않는다(스크롤과 함께 이동).
- 헤더: `{component.mobile-header}` — 좌: 제목 "지인" (`{typography.tagline}`), 우: `{component.button-primary}` compact "추가"
- 하단: `{component.mobile-tab-bar}` — "달력" / "모임" / "지인"(활성)

## 상태

- default (03이 만드는 상태): 소유자 "전체" + 그룹 "대학 동기" 선택, 10행. 실제 앱 초기값은 그룹 "전체 52"이며 레이아웃은 동일하게 52행.
- empty (지인 0명): 블록 1~6 → `{component.empty-state}` 제목 "아직 등록한 지인이 없어요" / 본문 "청첩장을 드릴 분을 한 명씩 등록하면, 모임을 만들 때 골라 쓸 수 있어요." / 버튼 "지인 추가" → `contact-edit`
- search-empty: 블록 6 → caption `{colors.ink-muted-48}` "'" + 검색어 + "'에 해당하는 지인이 없어요"
- group-empty (예: 그룹 "러닝 크루" 선택 시 사람은 4명 있으나 모임 0건): 이 화면에서는 정상 4행. "모임 없음"은 이 화면 관심사가 아님 — `edgeCases.emptyGroup`은 `meeting-create` 그룹 칩에서 다룸

## 엣지케이스 노출

- 중복 소속: 블록 6 p03 박민아 행에 [대학 동기][직장 동료] 칩 2개 (`edgeCases.multiGroupPerson`). 그룹 칩을 "직장 동료·신부"로 바꿔도 같은 행이 남는다.
- 1:1: 그룹 "직장 동료·신랑" 선택 시 p31 강민석 행 우측 "따로 만나기" (같은 형식으로 p14 조은비도)
- 양가: p52 정민규 [공동] 칩 (`edgeCases.bothSidePerson`) — "공동" 소유자 필터에서 유일하게 남는 행
- 긴 텍스트: p20 "마리아 페르난데스 데 라 크루스" 제목 1줄 말줄임, relation 2줄 (`edgeCases.longText`)
