# meeting-confirm — 확정

## 목적

최종 후보 선택 → 시간·장소 입력 → 겹침 재확인 → 확정·공유. PRD §4-4, §4-5(겹침 2차 경고).

## 진입 / 이탈

- 진입: `meeting-detail`(확정 대기 / 회신 대기) 스티키 "확정하기"
- 이탈: 헤더 뒤로가기 → `meeting-detail` / 스티키 "확정하고 공유" → OS 공유 시트 → `meeting-detail`(상태 `확정`) / 블록 2 행 탭 → 같은 화면, 선택 변경

## 프레임

- 390 × 844. 스크롤 없음(후보 5개면 콘텐츠 높이).
- 헤더: `{component.mobile-header}` — 좌: `{component.button-icon-circular}`(32px, chevron.left) / 우: 없음
- 하단: `{component.mobile-sticky-cta}` — 좌: body 선택 후보 `label` + " " + 시간 → "11월 29일 (일) 18:30", 우: `{component.button-primary}` "확정하고 공유"

## 상태

- default: 위 스택
- no-overlap: 후보 c2 선택 시 블록 6 숨김
- error: 장소 비우고 CTA → 블록 4 아래 caption "장소를 적어 주세요" (시간은 기본값이 있어 필수 통과)

## 엣지케이스 노출

- 겹치는 모임: 블록 6 — 확정 직전 2차 경고 (`candidates[c3].overlapWarning`)
- 늦은 회신: 블록 5 "미회신 1명 · 오준호" — 미회신 제외 확정 (`edgeCases.lateReplier`)
