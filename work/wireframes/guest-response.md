# guest-response — 지인 응답 (링크)

## 목적

앱·로그인 없이 링크로 열어 이름 선택 → 후보별 가능/불가 → 제출을 1스크롤·30초 안에 끝낸다. 확정 후엔 같은 링크가 시간·장소를 보여준다. PRD §4-3, §4-4.

## 진입 / 이탈

- 진입: 메신저 링크 (앱 밖). 탭바 없음
- 이탈: 스티키 "제출" → 같은 화면 상태 `submitted` / `submitted` 상태 버튼 "답변 수정" → 상태 `default` / 그 외 이동 없음 (P1 `guest-my-invites` 링크는 만들지 않음)

## 프레임

- 390 × 844. 후보 5개면 콘텐츠 높이.
- 헤더: `{component.mobile-header}` — 좌: 제목 `wedding.coupleLabel` + " 청첩장모임" → "지수·도현 청첩장모임" (`{typography.tagline}`) / 우: 없음
- 하단: `{component.mobile-sticky-cta}` — 좌: body 답한 후보 수 + "/" + 후보 수 + " 답함" → "3/3 답함", 우: `{component.button-primary}` "제출"

## 상태

- default: 위 스택
- submitted: 블록 2~5 → `{component.empty-state}` 제목 "답변 완료" / 본문 "확정되면 이 링크에서 시간과 장소를 볼 수 있어요." / 버튼 "답변 수정". 스티키 없음
- confirmed (m04 동네 친구 링크): 블록 1 줄 1 "동네 친구" / 줄 2 `confirmedLabel` + " · " + `place` → "11월 28일 (토) 19:00 · 연남동 소이연남" / 줄 3 "확정됐어요". 블록 2~5 → `{typography.tagline}` "함께 가는 사람" + `{component.list-row}` × 5 (제목 `name`, 우 없음). 스티키 없음
- urgent (m12 링크): 블록 3 행 1개, 블록 1 줄 3 "11월 20일 (금) 12:00까지 답해 주세요". 레이아웃 동일
- closed (마감 지남·미확정, m01 링크): 블록 1 줄 3 "마감이 지났어요. 답하면 바로 전달돼요" — 제출은 허용

## 엣지케이스 노출

- 급한 모임: 블록 1 줄 3 마감이 첫 스크롤 (`edgeCases.urgent` 상태 `urgent`)
- 늦은 회신: 마찰 최소화(가입 없음, 1스크롤) 자체가 대응. 상태 `closed`로 마감 후 회신도 받음
- 확정 공유(PRD §4-4): 상태 `confirmed`
