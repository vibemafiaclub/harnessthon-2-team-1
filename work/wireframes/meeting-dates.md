# meeting-dates — 일정 후보·마감

## 목적

날짜+시간대 후보 1~5개를 넣고, 각 후보 아래 겹침을 1줄로 알리며, 회신 마감을 반드시 정한 뒤 링크를 보낸다. PRD §4-3, §4-5(겹침 1차 경고).

## 진입 / 이탈

- 진입: `meeting-create` 스티키 "다음: 날짜 후보" / `meeting-detail`(준비 중) 스티키 "후보 보내기" / `meeting-detail`(확정) 좌 "날짜 다시 잡기"
- 이탈:
  - 헤더 좌 뒤로가기 → 직전 화면 (`meeting-create` 또는 `meeting-detail`). 후보·마감은 저장된 채 유지(`준비 중`)
  - 스티키 CTA "링크 보내기" → OS 공유 시트 → 닫히면 `meeting-detail` (상태 `회신 대기`)
  - 블록 4 "후보 추가" → 같은 화면, 블록 4a 열림 (상태 `adding`)
  - 블록 3 행 우측 "삭제" → 같은 화면, 행 제거

## 프레임

- 390 × 844 (후보 5개 + adding 상태면 콘텐츠 높이로 늘어남). 세로 스크롤.
- 헤더: `{component.mobile-header}` — 좌: `{component.button-icon-circular}`(32px, chevron.left) / 우: 없음
- 하단: `{component.mobile-sticky-cta}` — 좌: 요약 body "후보 " + 후보 수 + "개 · 마감 " + 마감 단축 → "후보 3개 · 마감 11/18", 우: `{component.button-primary}` "링크 보내기"

## 상태

- default: 위 스택 (후보 3, "직접" 마감)
- adding: 블록 4 → 4a
- urgent (m12 입사 동기): 블록 3 행 1개 "11월 21일 (토) 저녁" + 메타 "이 날 저녁에 '대학 동기(신부)' 후보 있음", 블록 6 "24시간" selected, 스티키 좌 "후보 1개 · 마감 24시간". 후보 1개로도 CTA 활성 — 레이아웃 변경 없음
- empty (후보 0개, 진입 직후): 블록 3 → caption `{colors.ink-muted-48}` "아직 후보가 없어요. 1개만 넣어도 보낼 수 있어요." 스티키 좌 "후보 0개"
- error: 후보 0개에서 CTA 탭 → 블록 3 자리 caption `{colors.ink}` "후보를 1개 이상 넣어 주세요"
- resend (`meeting-detail` 확정 → "날짜 다시 잡기" 진입): 블록 1 caption에 " · 다시 조율" 추가, CTA "링크 다시 보내기". 기존 회신은 초기화됨을 블록 8에 문구 "다시 보내면 지난 회신은 지워져요." 로 대체

## 엣지케이스 노출

- 겹치는 모임: 블록 3 c1·c3 메타 — 후보를 넣는 그 자리에서 1차 경고(brief C8 "두 번 알린다"의 첫 번째). `candidates[].overlapWarning`
- 늦은 회신: 블록 6 마감 필수 프리셋 (brief 가정 9)
- 급한 모임: 상태 `urgent` — 후보 1개 + "24시간" (`edgeCases.urgent` m12)
