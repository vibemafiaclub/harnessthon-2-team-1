# meeting-detail — 모임 상세·회신 현황

## 목적

후보별·구성원별 회신을 모아 보고, 미회신자와 마감을 첫 스크롤에 두어 다음 행동(리마인드·마감 연장·확정)을 고르게 한다. 상태 5개를 한 화면이 스티키 CTA 문구로 흡수한다. PRD §4-3, §4-6.

## 진입 / 이탈

- 진입: `home-meetings` 모임 행 / `calendar-overview` 선택 날짜 모임 행 / `meeting-dates` 링크 보내기 후 / `meeting-confirm` 확정 후
- 이탈:
  - 헤더 좌 뒤로가기 → 직전 화면 (`home-meetings` 또는 `calendar-overview`)
  - 스티키 우 CTA (상태별 표 참조): "확정하기" → `meeting-confirm` / "후보 보내기" → `meeting-dates` / "리마인드"·"링크 다시 공유" → OS 공유 시트(같은 화면 유지)
  - 스티키 좌 링크 (상태별): "마감 연장" → 같은 화면, 블록 2 아래에 마감 프리셋 칩 행이 열림 (상태 `extend`) / "날짜 다시 잡기" → `meeting-dates` (상태 `resend`)
  - 블록 3 미회신자 행 "리마인드" → OS 공유 시트
  - 블록 4 "구성원 변경" 링크 → `meeting-members-edit` (P1 — 03은 링크만 만들고 화면은 없음)

## 프레임

- 390 × 콘텐츠 높이 (약 1,300). 세로 스크롤. 첫 화면(844)에 블록 1~3(제목·요약·미회신자)이 들어가야 한다.
- 헤더: `{component.mobile-header}` — 좌: `{component.button-icon-circular}`(32px, chevron.left) / 우: 없음
- 하단: `{component.mobile-sticky-cta}` — 조합: 좌 `{component.text-link}` "마감 연장", 우 `{component.button-primary}` "확정하기" (default 상태 = 확정 대기). 상태별 문구는 아래 표

| 상태 (`status`) | 좌 (text-link)   | 우 (button-primary) | 비고                                 |
| --------------- | ---------------- | ------------------- | ------------------------------------ |
| preparing       | 없음             | "후보 보내기"       | → `meeting-dates`                    |
| awaiting        | "마감 연장"      | "리마인드"          | 리마인드 = 미회신자용 링크 공유 시트 |
| ready (default) | "마감 연장"      | "확정하기"          | → `meeting-confirm`                  |
| confirmed       | "날짜 다시 잡기" | "링크 다시 공유"    | 확정 정보 링크                       |
| done            | (스티키 없음)    | (스티키 없음)       | 하단 없음                            |

## 상태

- default (ready, m01): 위 스택
- extend: 블록 2 아래에 `{component.status-chip}` × 4 "24시간" "3일" "7일" "직접" + `{component.button-primary}` compact "연장" 행이 열림. 연장 시 `status` → awaiting, 블록 2 줄 2가 "마감 D-3 · …"로 바뀜
- awaiting (m12 입사 동기): 블록 1 칩 "회신 대기", 블록 2 "회신 2/3" / "마감 22시간 · 11월 20일 (금) 12:00" / 줄 3 "가장 많이 가능한 후보 11월 21일 (토) 저녁 · 2명", 블록 3 p44 백지안 "리마인드", 블록 4 행 1개 (메타 "이 날 저녁에 '대학 동기(신부)' 후보 있음"), 스티키 좌 "마감 연장" 우 "리마인드"
- preparing (m10 옆 팀 동료): 블록 1 칩 "준비 중", 블록 2 줄 1 "후보 없음" / 줄 2 "후보를 보내면 여기서 회신을 모아요" / 줄 3 없음. 블록 3·4 숨김. 블록 5 구성원 2행(p12 배현우, p13 신다은), 우측 기호 없음. 스티키 우 "후보 보내기"
- confirmed (m04 동네 친구): 블록 1 칩 "확정", 블록 2 줄 1 `confirmedLabel` "11월 28일 (토) 19:00" / 줄 2 `place` "연남동 소이연남" / 줄 3 caption `sameDayText` + ": " + 겹친 모임 `title`(`sideLabel`) → "같은 저녁 1건: 대학 후배(신랑)" (`sameDayText` null이면 줄 3 없음). 블록 3 숨김. 블록 4·5는 유지(회신 기록). 스티키 좌 "날짜 다시 잡기" 우 "링크 다시 공유"
- done (m08 팀 회식): confirmed와 같되 블록 1 칩 "완료", 블록 2 줄 3 없음, 하단 없음
- 03은 default 1개만 만든다. 나머지 상태 프레임 추가 여부는 게이트 2 결정 (decisions 2-4)
