# meeting-create — 모임 편성

## 목적

지인 풀에서 구성원을 골라 모임 하나를 만든다. 이미 다른 모임에 편성된 사람과 `따로 만나기` 지인을 행에서 알려 주되 선택은 막지 않는다. PRD §4-2.

## 진입 / 이탈

- 진입: `home-meetings`·`calendar-overview` 헤더 "새 모임" / `home-meetings`·`calendar-overview` 빈 상태 버튼
- 이탈:
  - 헤더 좌 뒤로가기 → 직전 화면 (`home-meetings` 또는 `calendar-overview`), 입력 폐기
  - 스티키 CTA "다음: 날짜 후보" → `meeting-dates` (모임은 `준비 중` 상태로 저장됨)
  - 블록 8 지인 행 → 같은 화면, 선택 토글 (상태 `selected`)
  - 블록 6 그룹 칩 / 블록 5 검색 → 같은 화면, 블록 8 필터

## 프레임

- 390 × 콘텐츠 높이 (약 1,100). 세로 스크롤.
- 헤더: `{component.mobile-header}` — 좌: `{component.button-icon-circular}`(32px, chevron.left) / 우: 없음
- 하단: `{component.mobile-sticky-cta}` — 좌: 요약 body 선택 수 + "명 선택" → "2명 선택", 우: `{component.button-primary}` "다음: 날짜 후보"

## 상태

- default: 위 스택 (선택 2, 경고 숨김)
- both (소유자 "공동"): 블록 6 칩 = "전체" + 그룹 8개(이름 중복은 "직장 동료·신부" 형식), 블록 8 각 행 메타 첫 칩에 `sideLabel` ("신부"/"신랑"/"공동"). 예: 상견례 편성 시 그룹 "가족·신부"에 p22 한정우·p23 이미경, "가족·신랑"에 p40 김영호·p41 박순자
- separate-warning: p14 조은비 + 다른 1명 이상 선택 → 블록 9 표시. 조은비만 단독 선택이면 경고 없음 (1명 모임 허용, 스티키 좌 "1명 선택")
- error: 모임 이름 비었거나 선택 0명에서 CTA 탭 → 블록 2 아래 caption "모임 이름을 입력해 주세요" 또는 블록 9 자리에 caption "구성원을 1명 이상 골라 주세요". 버튼 비활성 시각 없음
- search-empty: 블록 8 → caption `{colors.ink-muted-48}` "'" + 검색어 + "'에 해당하는 지인이 없어요"
- empty (지인 0명): 블록 4~8 → `{component.empty-state}` 제목 "고를 지인이 없어요" / 본문 "먼저 지인을 등록해 주세요." / 버튼 "지인 추가" → `contact-edit`

## 엣지케이스 노출

- 중복 소속: 블록 8 p03 박민아 — 칩 2개 + "'직장 팀' 모임에 편성됨" (이 사람을 어느 모임에 넣을지 판단하는 근거, `edgeCases.multiGroupPerson`)
- 1:1: 블록 8 p14 조은비 "따로 만나기" 메타 + 블록 9 경고 (상태 `separate-warning`). 구성원 1명 모임 허용 (`edgeCases.oneOnOne` m07 방식)
- 상견례: 블록 3 "공동" → 상태 `both`, 양측 가족 그룹이 한 목록에 (`edgeCases.bothSides` m09)
- 빈 그룹: 블록 6 "러닝 크루 · 모임 없음" (`edgeCases.emptyGroup` g06, 신랑/공동 필터에서)
