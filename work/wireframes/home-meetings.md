# home-meetings — 모임 목록

## 목적

전체 모임을 진행 상태별 섹션으로 조망하고, 처리할 것(확정 대기·마감 임박)을 첫 스크롤에 올린다. PRD §4-5, §4-6.

## 진입 / 이탈

- 진입: `{component.mobile-tab-bar}` 탭 2 "모임" / `calendar-overview` 블록 3 요약 행 (이 경우 블록 2 "확정 대기" 섹션이 첫 스크롤) / `meeting-detail` 뒤로가기
- 이탈:
  - 헤더 우측 "새 모임" → `meeting-create`
  - 모든 모임 행 → `meeting-detail` (해당 meetingId)
  - 빈 상태 버튼 → `meeting-create`
  - 탭바 "달력" → `calendar-overview`, "지인" → `contacts-list`

## 프레임

- 390 × 콘텐츠 높이 (약 1,600). 세로 스크롤. 첫 화면(844)에는 블록 1~4(확정 대기 + 회신 대기 3건)가 들어가야 한다.
- 헤더: `{component.mobile-header}` — 좌: 제목 "모임" (`{typography.tagline}`), 우: `{component.button-primary}` compact "새 모임"
- 하단: `{component.mobile-tab-bar}` — "달력" / "모임"(활성) / "지인"

## 레이아웃 스택 (위→아래)

## 상태

- default: 위 스택 (필터 "전체")
- empty (모임 0개): 블록 2~7 → `{component.empty-state}` 제목 "아직 모임이 없어요" / 본문 "지인을 골라 첫 모임을 만들고 날짜 후보를 보내 보세요." / 버튼 "새 모임 만들기" → `meeting-create`
- filtered-empty (예: 필터 "공동"에 확정 외 항목 없음): 항목 0인 섹션 숨김. 전체가 0이면 caption `{colors.ink-muted-48}` "공동 모임이 없어요" 1줄
- from-summary (홈 요약 행 진입): 스크롤 위치가 블록 2에 오도록. 레이아웃 동일
