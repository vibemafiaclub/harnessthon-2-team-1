## F3. 최소 라이브러리 (완료)

출력 파일 `Library` 페이지(1:2)에 6종 완성:
- `Button` — primary/secondary × default/pressed, pill 999px 라운드(0단계 형태 확정값)
- `Chip` — 회신대기/확정대기/확정/완료 × default/selected, 상태색은 F2 색상표(status-warning/action-primary/status-success/status-neutral) 그대로 바인딩
- `TopBar` — 뒤로가기 벡터 아이콘 + 제목(중앙정렬, 좌우 균형용 spacer)
- `BottomNav` — 홈/모임/지인풀 3탭, 실벡터 아이콘(홈/캘린더/유저스 path 재사용, 자리표시자 없음)
- `Cell/List` — 원형 아이콘 타일(하트, accent-icon 15% 배경) + 제목/메타 2줄, default/pressed
- `Field` — 라벨+값 2줄 + 우측 chevron(▾)

변수 컬렉션 `toss-invite tokens`(16색, `color/*` 네이밍). 폰트 확인 완료: Noto Sans KR(Regular/Medium)·Oswald 둘 다 이 환경에서 사용 가능.

**실측 함정**: `figma.createComponent()` 후 자식을 다 붙이고 나서 `combineAsVariants`를 부르면 "Grouped nodes must be in the same page as the parent" 에러. 해법: 컴포넌트를 만들자마자 `page.appendChild()`부터, 자식도 만들자마자 `parent.appendChild()`부터 하고 그다음 속성 설정. `references/figma-snippets.md` §2에 기록함.
