# User Flow — 픽스처

## 1. 핵심 경로
### 경로 A. 등록자 (ROLE-01)
| 단계 | 화면 | 내용 |
|---|---|---|
| 진입 | SCR-01 | 목록을 본다 |
| 입력 | SCR-02 | 항목을 입력한다 |
| 처리 | SCR-02 | 저장한다 |
| 결과 | SCR-01 | 목록에 반영된다 |
| 다음 행동 | SCR-01 | 다음 항목을 등록한다 |

## 2. 항목 상태 전이
### 상태
| ID | 상태 | 설명 | 종료 상태 |
|---|---|---|---|
| ST-01 | 작성중 | 저장 전 | 아니오 |
| ST-02 | 저장됨 | 저장 후 | 예 |
### 전이
| From | To | 트리거 | 유형 | 주체 | 화면 | 알림 대상 | 비고 |
|---|---|---|---|---|---|---|---|
| ST-01 | ST-02 | 저장 | 사용자 | ROLE-01 | SCR-02 | 없음 | |

검토 포인트:
- 시간 기반 전이: 없음
- 되돌리기: 없음
- 우회: 없음

## 3. 유저 플로우
### FLW-01 항목 등록 — ROLE-01
트리거: 새 항목을 남기려 할 때

| 순서 | 화면 | 행동 | 결과 |
|---|---|---|---|
| 1 | SCR-02 | 입력하고 저장 | ST-02 진입 |

결과: 목록에 반영된다.

예외:
- 입력값이 비어 있음 → 저장을 막고 오류를 표시한다

|---|---|
