# IA — 청첩장모임 스케줄러

> `wireframe` 스킬 입력 문서 3/4. ia.yaml의 엔티티(ENT-01~07), 화면 목록(SCR-01~10), 내비게이션을 정리했다.

## 1. 엔티티

| ID | 이름 | 설명 | 핵심 필드 |
|---|---|---|---|
| ENT-01 | 지인 | 예비부부가 청첩장을 전달할 대상. 신랑측·신부측 계정 중 한쪽이 등록한다 | 이름(필수), 연락처(필수, ROLE-03 전역 식별 키), 메모(선택, 예: 대학 동기), 등록 계정, 생성일 |
| ENT-02 | 그룹 | 지인을 묶는 사용자 정의 분류. 계정별로 독립 관리 | 그룹명, 소유 계정, 생성일 |
| ENT-03 | 모임 | 하나 이상의 지인과 날짜를 조율해 확정하는 단위. 핵심 엔티티이며 상태 전이의 대상 | 커플, 제목(선택), 상태(ST-01~05), 작성 계정, 회신 마감(필수), 확정된 날짜후보(확정 후), 긴급 우회 여부, 생성일 |
| ENT-04 | 날짜후보 | 모임에 제안된 날짜·시간 옵션 | 모임, 일시, 메모(선택) |
| ENT-05 | 회신 | 지인이 특정 날짜후보에 남긴 참석 가능 여부 | 날짜후보, 지인, 가능/불가능/미응답, 회신 일시 |
| ENT-06 | 계정 | 예비신부(ROLE-01) 또는 예비신랑(ROLE-02)의 로그인 계정 | 이름, 측(신부/신랑), 연락처, 커플(연결 전엔 비어 있음), 생성일 |
| ENT-07 | 커플 | 서비스를 함께 쓰는 예비부부 단위. 통합 조망(REQ-10)의 기준 | 결혼식 날짜(선택), 생성일 |

### 관계

| From | To | 유형 | 비고 |
|---|---|---|---|
| ENT-01 지인 | ENT-02 그룹 | N:M | RISK-01. 중복 소속 허용. 지인 목록에서 소속 그룹 태그를 모두 노출. 그룹을 삭제해도 지인은 남고 태그만 제거 |
| ENT-01 지인 | ENT-03 모임 | N:M | 한 지인이 여러 모임에 동시에 참가 가능(1:1 모임 포함) |
| ENT-03 모임 | ENT-04 날짜후보 | 1:N | 모임 하나에 후보 여러 개 |
| ENT-04 날짜후보 | ENT-05 회신 | 1:N | 후보 하나에 참가자별 회신 여러 건 |
| ENT-07 커플 | ENT-06 계정 | 1:N | 정확히 2개(신부측 1, 신랑측 1). 그 이상·이하는 앱 레벨에서 막는다 |
| ENT-07 커플 | ENT-03 모임 | 1:N | 통합 조망의 기준 |

## 3. 화면별 핵심 정보·행동·상태

### SCR-01 홈

- 핵심 정보: 진행 상태별 모임 건수(회신중/확정대기/확정/완료), 이번 주 확정 모임 목록, 회신 마감이 임박했거나 지난 모임 알림
- 행동: 모임 편성으로 이동, 전체 일정 조망으로 이동, 지인 관리로 이동
- 상태: Empty(지인·모임이 하나도 없는 최초 진입 → 지인 등록으로 유도, RISK-07), Loading

### SCR-02 지인 목록

- 핵심 정보: 지인 이름, 소속 그룹 태그(복수 노출), 연락처, 전체 등록 인원 수
- 행동: 지인 추가, 지인 상세/수정 진입, 그룹별 필터, 이름 검색
- 상태: Empty(0명, RISK-07), Large dataset(100명 이상 → 검색·그룹 필터 필수, RISK-06), Loading

### SCR-02.1 지인 등록/수정

- 핵심 정보: 이름·연락처 입력값, 기존 그룹 다중 선택, 새 그룹 즉시 생성
- 행동: 저장, 취소, 삭제(수정 모드)
- 상태: Error(연락처 형식 오류·이름 미입력), Loading
- 비고: 뒤로가기 시 SCR-02로 복귀하므로 독립 화면이 아닌 부속 화면

### SCR-03 그룹 관리

- 핵심 정보: 그룹명, 그룹별 소속 인원 수
- 행동: 그룹 생성, 그룹명 수정, 그룹 삭제
- 상태: Empty(RISK-07), Loading

### SCR-04 모임 목록

- 핵심 정보: 모임명 또는 참가자 요약, 진행 상태 배지(회신중/확정대기/확정/완료/취소됨), 회신 마감일 또는 확정일, 회신 현황(n/m)
- 행동: 모임 편성으로 이동, 상태별 탭 선택, 모임 상세로 이동
- 상태: Empty(탭별 0건, RISK-07), Partial(마감 전 일부만 회신, RISK-08), Large dataset(40건 이상 → 필터·정렬, RISK-06), Loading

### SCR-05 모임 편성

- 핵심 정보: 선택 가능한 지인 목록(그룹 필터 포함), 선택된 인원 수, 제안할 날짜 후보 목록, 회신 마감 입력값, 긴급 모임(우회) 여부
- 행동: 지인 선택/해제, 날짜 후보 추가/삭제, 회신 마감 설정, 긴급 모임으로 바로 확정(후보 제안 생략), 모임 생성
- 상태: Empty(등록된 지인 없음 → 지인 등록 유도), Error(날짜 후보 미입력 등, 긴급 모임 아닌 경우), Loading

### SCR-06 모임 상세

- 핵심 정보: 참가자별 회신 현황(가능/불가능/미응답), 날짜 후보별 가능 인원 수, 회신 마감까지 남은 시간 또는 마감 초과 여부, 같은 날짜에 겹치는 다른 모임 경고(RISK-03), 확정된 날짜(확정 후)
- 행동: 날짜 확정, 회신 마감 연장, 구성원 추가/제외, 모임 취소
- 상태: Partial(일부만 회신, RISK-08), Error(전원 불가능으로 확정할 날짜 없음), No-permission(배우자가 만든 모임은 열람만, 확정·취소는 POL-01 조건부), Loading
- 비고: 상태(회신중/확정대기/확정/완료/취소)별로 보여줄 정보와 가능한 행동이 크게 다르다. 사실상 5개 변형을 하나의 SCR로 묶은 것이므로 설계 난이도가 가장 높다

### SCR-07 전체 일정 조망

- 핵심 정보: 월별 확정 모임 목록, 날짜별 모임 건수, 겹치는 날짜 강조, 신부측/신랑측/공동(양가) 구분
- 행동: 월 이동, 특정 모임 상세로 이동
- 상태: Empty(확정 모임 없음, RISK-07), Loading

### SCR-08 내 초대 목록

- 핵심 정보: 요청한 커플 또는 모임명, 회신 마감까지 남은 시간 또는 마감 초과 여부, 회신 완료/미응답 여부, 여러 커플의 요청을 모두 목록으로 노출
- 행동: 모임별 회신 화면으로 이동
- 상태: Empty(요청이 이 하나뿐 → 목록 없이 바로 회신 화면으로 진입해도 무방, TBD), Error(만료되거나 유효하지 않은 링크), Loading

### SCR-09 회신 입력

- 핵심 정보: 모임을 제안한 커플/구성원 정보, 날짜 후보 목록과 마감 기한, 확정된 경우 최종 날짜
- 행동: 날짜별 가능/불가능 선택, 회신 제출 또는 수정
- 상태: Error(마감 지남 → 입력 불가, 확정 날짜 있으면 결과만 표시, RISK-02), No-permission(유효하지 않은 초대 식별자), Loading

### SCR-10 계정 설정

- 핵심 정보: 배우자 연결 상태(연결됨/미연결), 배우자 초대 코드 발급/입력, 내 계정 정보(이름·연락처)
- 행동: 배우자 초대 코드 생성, 코드 입력해 연결, 내 정보 수정
- 상태: Empty(배우자 미연결 → 통합 조망 사용 전 필수 단계), Error(잘못되었거나 이미 사용된 코드), Loading

## 4. 내비게이션 구조

### 인증 사용자 (ROLE-01, ROLE-02)

```
SCR-01 홈
├── SCR-02 지인 목록
│   ├── SCR-02.1 지인 등록/수정
│   └── SCR-03 그룹 관리
├── SCR-04 모임 목록
│   ├── SCR-05 모임 편성
│   └── SCR-06 모임 상세
├── SCR-07 전체 일정 조망
└── SCR-10 계정 설정
```

### 비인증 사용자 (ROLE-03)

```
초대 링크
└── SCR-08 내 초대 목록
    └── SCR-09 회신 입력
```

두 트리는 컴포넌트를 공유하지 않는다. ROLE-03 화면에 로그인 사용자 화면의 컴포넌트를 그대로 재사용하지 않는다.
